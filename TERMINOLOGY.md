# DEPENDANTS
Dependants or dependents, are refered as the Developer, Software of Project that relies on another software, in this context
Minecraft Modders or desktop apps using WATERMeDIA as the API in between the backend is considered a dependant

# MIXINS
Mixin is a SpongePowered library that provides bytecode manipulation trough Java classes in Runtime without modify any
source code, therefore, it does NOT interact with Javac to perform these modification, as be a local and runtime only modification, 
is excepted of any Copyright Infringement.

# ENGINES
Engines are referred as the technology behind the data transformation into a perceptible reality, as is sound or video.
Libraries like OpenAL and OpenGL are APIs that interact with the hardware, procesing the data into real world perception.
WaterMedia is an engine composed by 2 other engines combined (WaterMedia + OpenGL or FFMPEG + Vulkan) performing the data transform into
real world perception
